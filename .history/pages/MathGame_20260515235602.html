Math Game -- Programming I

In programming I we learned how to make a menu that prompts users a choice between math games. For demonstration purpose, I will show Collatz Conjecture.

First, user is prompted to choose an integer number. the code will then evaluate the number to see if it's even or odd.

Second, there is 2 counters, 1 for number between 1 and 100 and then another counter over 100. Count stops until the number prompted reaches 1.
